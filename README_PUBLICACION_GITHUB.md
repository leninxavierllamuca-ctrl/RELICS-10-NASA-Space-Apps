# RELICS 10.0 — repositorio público de código

Este directorio es una **copia para mostrar el código** del proyecto RELICS 10.0 durante NASA Space Apps Sangolquí 2026. Incluye los nueve módulos, las preguntas y niveles, la interfaz web, el laboratorio 3D, las fuentes, las transformaciones de datos NASA y el código Android/servidor; el `LICENSE` original MIT se conserva en la raíz.

Esta copia **excluye deliberadamente** nueve videos comerciales o de terceros y sus copias Android, archivos CAD derivados de GrabCAD, capturas CAD y material multimedia que requiere permiso de publicación. Los recursos multimedia siguen presentes en el ZIP completo conservado por el equipo. El repositorio sin dichos archivos es evidencia de código, **no una versión de demostración multimedia completa**.

## Cómo cargar a GitHub con el navegador

1. Descomprime `GITHUB_SUBIR_ESTOS_ARCHIVOS.zip` en tu PC.
2. Abre el repositorio público GitHub del equipo y haz clic en `uploading an existing file` o `Add file > Upload files`.
3. Entra en la carpeta descomprimida y selecciona **todo su contenido**, no la carpeta contenedora ni el ZIP.
4. Arrastra esos archivos y carpetas juntos al cuadro central de GitHub. Comprueba que `LICENSE` y `README.md` aparezcan **directamente** en la raíz.
5. Escribe `Subida inicial del código RELICS 10.0` y pulsa `Commit changes`.
6. Abre en modo incógnito el enlace del repositorio para confirmar que es público. Copia el URL exacto y colócalo en `Ficha_Proyecto_ES_EN.pdf`.

Los botones que enlazan a MP4 no reproducirán esos videos desde esta copia pública. Para demostrar videos y laboratorio, utilice una demo autorizada, una captura o un video breve accesible mediante enlace distinto.

**Fuente NASA utilizada:** [Apollo Lunar Surface Experiments Package Arrays and Status](https://www.nasa.gov/wp-content/uploads/static/history/SP-4029/Apollo_18-31_ALSEP_Arrays_and_Status.htm). Véase `datos/` para CSV, cálculo y JSON derivado.
